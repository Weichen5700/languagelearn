# 外語沉浸擷取（Chrome 擴充）

在 YouTube 字幕上點擊單字 → 自動翻譯、查字典、帶語境擷取回本機外語學習網站。
為 `外語學習嘗試` 專案的沉浸式學習模組（詳見根目錄 `IMMERSION.md`）。

## 安裝（載入未打包擴充）

1. 啟動本機網站：在 repo 根目錄 `npm run dev`（預設 `http://localhost:3000`）。
2. Chrome 開啟 `chrome://extensions` → 右上開啟「開發人員模式」。
3. 「載入未打包」→ 選本資料夾 `apps/extension`。
4. 開 YouTube 任一有字幕的外語影片，字幕單字會變成可點擊（hover 變黃）。

## 使用

- 點字幕單字 → 浮層顯示譯文，同時擷取（單字 + 整句 + 影片時間）送回本機站。
- 本機網站需開啟以即時合併進 IndexedDB（沉浸卡）；未開時暫存於擴充，開站補傳。
- 點擴充圖示設定：本機網址、字幕語（目標外語）、翻譯母語、啟用開關、Listening Mode、側欄預設展開、Hover 預覽。
- 🖱️ **點擊工具列圖示＝切換擷取視窗（開 / 關）**，圖示右下角徽章顯示 `ON` / `OFF`；設定頁請由**右鍵圖示 → 選項**開啟（與下方「啟用開關」同步）。
- 🔑 **翻譯 / 字典 / TTS 的 API Key 由本機網站後端託管**（最安全，Key 不下發前端）。在 web app 的 **設定頁 `/settings`** 貼上 `GOOGLE_API_KEY` 等（AES-256-GCM 加密存於本機 `data/.keys/`，前端只見遮罩狀態）；或在 `.env.local` 設定（設定頁優先）。擴充套件只把查詢送往本機 `/api/*`。popup 內「🔌 測試連線」可驗證本機站是否啟動。

## 統一右側側欄（單一面板）

固定在 YouTube 右側的側欄，整合「字幕記錄 + 速度控制 + 存情境」，不再三塊分散浮層、也不會因操作其他地方而消失。
- **字幕記錄**：當前句＋前數句（前後文），每字可點擊查詞典擷取。緩衝依 `startSec` 排序為一條真實時間軸（上限 120 句，超過從最舊者淘汰），側欄可捲動/拖曳瀏覽歷史。**跳轉安全**：不限制單調前進，自由倒帶重播；靠「時間鄰近（10s）+ 文字重疊」去重——同句重顯、倒帶漸進前綴皆 no-op，前綴延伸／滾動視窗尾首重疊則合併為完整句並保留原始時間軸，新句才依 `startSec` 插入正確位置。**現在播放句**依 `video.currentTime` 即時標示（黃色左軸＋高亮），且 `now - startSec ≤ 12s` 才高亮（段落空隙不高亮），隨 `timeupdate`／`seeked` 更新；跳轉後自動置中對齊到正確段落。貼著 now-playing 時自動隨播放捲動，往上拖曳瀏覽歷史時暫停追蹤並顯示「↓ 目前」按鈕可跳回。換影片時自動清空緩衝。
- **速度控制**：嵌入側欄頂部的速度列（0.5×–2×），點按鈕即切換 `video.playbackRate`，當前速度黃色高亮；YT 內建選單改速會同步回寫。
- **存情境**：側欄底部「🎬 存情境 (Q)」按鈕，取最近 5 句一次擷取。
- **連線狀態**：底部顯示與本機站的連線狀態（綠/紅/灰點）。
- **收合**：點側欄左緣的 ▶/◀ 握把或快捷鍵 `P` 展開/收合；收合時僅露 34px 握把。
- `↺` 重播最後一句（跳回其時間軸並播放）。
- 在 popup 勾選「預設展開右側側欄」可預設啟用/停用。

## 擷取對話框

點字幕單字（YT 原生或側欄內）改為先開擷取對話框，可檢視/編輯後再送：
- 切換「單字 / 整句」範圍；單字與整句欄位皆可編輯。
- 預覽當下影格截圖、時間軸（mm:ss）與「在 YouTube 開啟此時間點」連結。
- **完整字典資訊**：背景查詢譯文並顯示，同時顯示詞性、釋義、例句；`🔊` 鈕呼叫本機 `/api/tts` 發音（失敗時降級瀏覽器原生語音）；`↺ 重播此句` 跳回該句時間軸。
- **API 狀態列**：明確顯示翻譯 / 字典 / 擷取各步驟的成功（✓）或失敗（✗），區分「API 錯誤」與「查無結果」。
- 送出後才正式擷取進本機站（離線則暫存）；`Esc` 取消。

## Hover 即時查詢

滑鼠移過任何字幕單字（YT 原生或面板），停頓約 0.3 秒即顯示譯文預覽浮層，無需點擊。
- 結果以單字為鍵記憶體快取，重複 hover 不重打 API。
- 在 popup 勾選「Hover 即時查詢預覽」可啟用/停用（預設開）。

## Listening Mode

開啟後字幕模糊（逼聽力），hover 單段字幕可暫時解除模糊對照。

## 離線暫存

擷取失敗（本機站未開）時存入 `chrome.storage.local`，每 60 秒自動重試；
popup 內「立即補傳暫存」可手動觸發。

## 檔案

| 檔案 | 用途 |
|---|---|
| `manifest.json` | MV3 資訊清單 |
| `src/background.service.js` | 工具列圖示點擊 → 開關擷取視窗 + ON/OFF 徽章 |
| `src/content.js` | YouTube 字幕解析 + 點擊擷取 + 離線暫存 |
| `src/content.css` | word span / 模糊字幕 / 側欄 / 對話框樣式 |
| `src/popup.html` / `popup.js` | 設定與補傳介面 |
| `icons/icon.svg` | 圖示原始檔（貓頭鷹，品牌色 `#58cc02`） |
| `icons/icon{16,32,48,128}.png` | 上架用圖示（由 `icon.svg` 產生） |

## 圖示

圖示由向量原稿 `icons/icon.svg` 產生，改圖後重新產生：

```bash
cd apps/web && npm run icons   # 需要 sharp（npm ci 已含）
```

`manifest.json` 的 `icons` 與 `action.default_icon` 皆指向這 4 個尺寸。

## 指向部署站（非本機）

1. 擴充設定頁把「本機網址」改成部署網址（例如 `https://your-app.vercel.app`）
2. `manifest.json` 的 `host_permissions` 加入該網域：
   ```json
   "host_permissions": [
     "http://localhost/*",
     "http://127.0.0.1/*",
     "https://your-app.vercel.app/*"
   ]
   ```
3. `chrome://extensions` → 重新載入擴充

> 預設僅開 `localhost` / `127.0.0.1`，不外連；自行加上的網域請確認是信任的自架站。
